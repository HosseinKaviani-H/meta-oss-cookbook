# Muse Spark Open Cookbook

Muse Spark Open is the open-weight release of Muse Spark: an 816B-parameter mixture-of-experts model with 42B active parameters, built for agentic and coding work. It takes text, image, audio, and video input, produces text, and has a 1,048,576-token context window.

## Get started

| You want to | Go to |
|---|---|
| Download the BF16 or NVFP4 checkpoint | [`meta-models/Muse-Spark-Open-816B-A42B`](https://huggingface.co/meta-models/Muse-Spark-Open-816B-A42B) on Hugging Face |
| Serve it with SGLang, vLLM, TensorRT-LLM, or another runtime, or call a hosted provider | [Run inference](https://dev.meta.ai/docs/muse-spark-open/deploy) |
| Write prompts, set reasoning strength, and call tools | [Prompting guide](https://dev.meta.ai/docs/muse-spark-open/prompting) |
| Fine-tune it | [Post-training](https://dev.meta.ai/docs/muse-spark-open/post-training) |
